# island-linux — Wayland / Niri 统一顶栏双岛与系统托盘原型规范

> **项目定位**：面向 Linux Wayland 桌面环境（Niri / Hyprland / Sway）的顶栏效率中枢与系统托盘一体化组件。  
> **当前阶段**：基于 **纯净深邃黑曜石（Obsidian）质感** 与 `UnifiedHost` 单一 `rAF` 物理调度器的完整交互原型定稿，后续将基于此规范开展 Linux 原生工程落地。  
> **主原型预览**：直接用现代浏览器打开 [dock.html](./dock.html)（首次加载 Tailwind CSS 与 Inter 字体需联网）。

## 1. 统一顶栏空间架构与模块能力

[dock.html](./dock.html) 将顶栏划分为**中置双岛效率区**与**右侧系统托盘控制区**，支持居中对称与靠右挤压两种自适应拓扑。

### 1.1 中置双岛（效率、媒体与代理状态中枢）

* **左岛（个人效率与媒体中枢 · 收起态 `222×40px`，展开 `416px` 宽）**
  * **时间与活力热力图（高度 `216px`）**：22 周活跃度网格（按列波浪入场并自动释放动画锁）、底层 Matrix 字符雨（`ResizeObserver` 零抖动）与鼠标轨迹粒子光晕、悬停弹性日期预览，以及**点击单格锁定 / 移出回显锁定详情 / 点击空白解锁**。
  * **辅助粘贴板（高度 `250px`）**：高对比度深色搜索过滤、图片缩略图与 `0.34s` **动态锚定视口防溢出**大图/全文浮层预览、FLIP 平滑置顶重排、删除/置顶事件隔离、新条目呼吸光晕，以及基于 `parseClipboardNodeSpec` 的 `vless://` / `vmess://` / `trojan://` / `ss://` 节点链接一键嗅探导入。
  * **文件暂存工作栏（高度 `256px`）**：支持拖入唤醒（Drag-to-Wake），暂存本地文件、文件夹、`.desktop` 快捷方式与文本片段；悬停 `0.5s` 弹出只读预览，拖出岛外越界时显示脱离态与还原提示，释放即可移除。
  * **媒体控制卡片（高度 `146px`）**：
    * **共享元素连续变形（Shared Element Morph）**：展开/回缩期间独立封面代理平滑插值位置、尺寸（`20px ↔ 96px`）、圆角（`6px ↔ 48px`）、黑胶沟槽显隐与内部图标尺寸，回缩时按最短路径回正至 `0°`。
    * **拟物黑胶 2.0 与流光动效**：轻量化预烘焙黑胶细纹旋转盘面与静止斜向玻璃高光层分离、曲目主题双光源极光背景（Ambient Mesh Glow）、随机 / 列表循环 / 单曲循环真实三态联动、`PointerEvent` 防脱手进度条，以及收起态溢出歌词平滑滚动；并订阅右岛全局静音事件实时联动 EQ 音柱状态。
* **右岛（`v2rayN` 极简代理状态岛 · 收起态 `40×40px`，展开 `456×466px`）**
  * **收起态纯状态圆点**：平时保持 `40×40px` 纯净状态圆岛，通过绿/灰/红三态指示代理正常、关闭与节点超时。
  * **场景快捷切换与吞吐图**：开发分流 / 游戏 TUN / AI 全球场景切换联动氛围漫射光、出口 IP 与流媒体/AI 解锁徽章；支持系统代理与 `sing-box` TUN 双开关、Rule / Global / Direct 三段式滑块、真连接批量测速（附带声纳扩散波纹）及三次贝塞尔实时上下行曲线。
* **双向共存与合岛融合（`#fusedIsland`）**
  * **分离态镜像互让**：左岛展开时右岛保持 `40×40px` 圆点贴靠右侧；右岛展开时左岛收缩为 `78×40px` 迷你胶囊停靠左侧，支持点击直接切换焦点。
  * **物理拖拽融合 / 撕裂分裂**：通过 `PointerEvent` + `setPointerCapture` 拖拽两岛靠近，触发向心碰撞挤压与 `372×42px` 超级控制条合体；合岛支持原地展开为 `468×266px` 双栏联合中控，撕裂拖拽则直接弹射拆回双岛。

### 1.2 右侧系统托盘与控制中心（Right Dock · `#rightDockShell`）

* **顶部常驻状态条（`40px` 高）**：集成后台托盘折叠抽屉（`^`）、`Fcitx5` 输入法（左键秒切中/英，右键打开方案选择面板）、Wi-Fi / 蓝牙 / 音量（支持悬停滚轮盲操调音量与亮度）/ 电池百分比组合胶囊，以及邮件与通知未读角标。
* **模块化展开面板与子页路由**：
  * **控制中心面板（`360×404px`）**：包含 Wi-Fi、蓝牙、深色模式、夜灯、勿扰与截图磁贴，亮度/系统音量滑块与**二级确认电源动作抽屉**；支持无缝进入**网络 / 蓝牙 / 音频详情子页**（含独立应用音量混音器 `app-mixer-range`、音频输出设备切换与麦克风静音开关 `#swMicMute`）。
  * **输入法方案 / 邮件通知 / 托盘溢出抽屉**：支持方案切换、通知已读与选项卡切换、托盘后台应用选中与快捷退出。
* **靠右挤压与自适应竖排（`.is-vertical`）**
  * 开启中岛「靠右让位」后，中置双岛统一基于 `dockShiftX` 完整复用物理坐标系平移至右上角；同时右岛顺滑切换为 `46px` 宽贴边垂直轨，展开卡片自动向左延展，互不遮挡。
  * 窄屏与矮屏保护：针对较小视口动态收紧右岛安全间距（防止代理面板与右岛碰撞），并依据视口可用高度自动钳制展开面板最大高度。

## 2. 纯粹黑曜石视觉、UnifiedHost 调度与交互工程细节

### 2.1 纯净深邃黑曜石材质体系（Pure Deep Obsidian）

* **统一材质收敛**：全组件收敛为唯一高定黑曜石碳黑磨砂玻璃基底，配合 `backdrop-filter` 与高纯度微冷白内高光折光边、极细暗色外描边与克制悬停氛围光，避免多余高饱和光污染，保证桌面长期常驻时的专注度。
* **壁纸压力测试**：内置「深空」「高亮（`.wp-bright`）」「炫彩（`.wp-cyber`）」三套桌面背景与全局亮度/夜灯遮罩；在高亮及高彩壁纸下通过提高组件表面不透明度与加深边框对比度，保证中岛、右岛与 HUD 提示文字清晰可读。

### 2.2 `UnifiedHost` 单一 `rAF` 物理调度与跨岛协同

* **单帧合批物理循环**：`window.UnifiedHost` 管理全局唯一 `requestAnimationFrame` 主循环，统一推进中岛与右岛的所有阻尼谐振子，每帧仅执行一次 DOM 几何应用，静止即自动休眠（0 帧空转），并支持 `prefers-reduced-motion: reduce` 降级与 `tabular-nums` 防数字抖动。
* **三套可调物理阻尼配置（`SPRING_PROFILES`）**：
  * `apple`（**Cult 柔弹**，`k=215, c=21`）
  * `liquid`（**液态丝滑**，`k=150, c=18`）
  * `snappy`（**极速干脆**，`k=350, c=30`）
* **跨岛事件总线与公共工具**：
  * 提供 `H.on / H.off / H.emit` 事件总线（如右岛静音与音量改动通过 `system:audio` 实时同步至中岛播放器）。
  * **统一 HUD 与防飞入 Tooltip**：底部/下方悬浮 HUD（`#unifiedHudIsland`）与原生辅助提示（`#skiperTooltip`）采用**外层瞬时定位、内层卡片原地舒展动画（`.tt-snap` / `.hud-snap`）**，消除初次触发从边角飞入及跨岛飘移的问题。
  * **无滚动副作用的容器裁剪**：所有形变岛壳（`.morph-island` / `.left-pill-bar`）采用 `overflow: clip` 与 `scrollIntoContainerView` 局部滚动定位，确保键盘遍历焦点时外层胶囊零错位滚动。
  * **全屏流光呼出条（`#centerPeekStrip`）**：全屏隐藏模式下顶部保留 `148×5px` 流光提示条，并同步响应居中/右上角停靠方位。

## 3. 快捷操作与键盘流规范

> 注：Web 原型使用 `Alt` 映射 Linux 桌面的 `Super` 键；面板内置焦点管理与 `Esc` 逐级收起。

### 3.1 鼠标快捷操作

* **左岛 / 合岛左侧（含合岛展开左卡）滚轮**：循环切换 `时间活力图 ↔ 辅助粘贴板 ↔ 工作栏 ↔ 音乐播放器`。
* **右岛代理状态圆点右键 / 合岛右侧状态胶囊左键**：快捷开/关总代理（记忆系统代理与 TUN 组合状态）。
* **右岛音频/电源状态槽悬停滚轮**：不展开控制中心直接盲操调节系统音量或屏幕亮度。
* **右岛 `Fcitx5` 图标**：左键秒切中/英文，右键展开详细输入法方案面板。

### 3.2 全局快捷键与面板内键盘导航

| 快捷键 | 作用域与行为 | 重复按下 / 次级导航 |
| :--- | :--- | :--- |
| `Alt + Space` | 分离态打开/收起左岛默认面板；合岛态展开/收起联合中控 | 再次按下平滑收起 |
| `Alt + V` | 直达「辅助粘贴板」并自动聚焦搜索框 | 再次按下收起；面板内支持 `↑/↓` 选行、`Enter` 复制、`Space` 预览、`Delete` 删除 |
| `Alt + W` | 直达「文件暂存工作栏」 | 再次按下收起；面板内支持 `↑/↓/Enter/Space` 选中与预览 |
| `Alt + P` | 展开「代理控制中心」并触发批量真连接测速 | 再次按下收起；面板内支持 `←/→` 切路由模式、`↑/↓/Enter` 切节点 |
| `Alt + A` | 打开/收起右侧「控制中心」 | 进入网络/蓝牙/音频子页后支持 `← / Backspace` 返回上级 |
| `Alt + N` | 打开/收起右侧「邮件与通知中心」 | 支持 `Tab / ← / →` 切换标签与 `↑/↓` 列表导航 |
| `Alt + I` | 打开/收起右侧「`Fcitx5` 输入法面板」 | 支持 `↑/↓` 移动高亮与 `Enter / Space` 切换方案 |
| `Alt + T` | 打开/收起右侧「系统托盘折叠抽屉」 | — |
| `Esc` | 优先取消电源二次确认或返回上级子页，再收起当前展开面板 | 逐级退回直至全收起态 |

## 4. Linux 原生落地技术路线参考

* **路线 A：Wayland 原生轻量组件（首选推荐）**
  * **技术栈**：`GTK4` + `gtk4-layer-shell`（Rust 或 Python） / `Quickshell` / `AGS`。
  * **优势**：无独立浏览器内核，常驻内存占用低，直接挂载 Wayland `Top` 层并利用合成器硬件加速。
* **路线 B：复用现有前端动效架构**
  * **技术栈**：`Tauri v2`（WebKitGTK） + Rust 守护进程 + `gtk-layer-shell` 绑定。
  * **系统接口对接**：
    * **代理控制**：`v2rayN` / `sing-box` Clash RESTful API 与流量 WebSocket；
    * **剪贴板与拖放**：`wl-clipboard` + Wayland `wl_data_device`；
    * **媒体控制**：`MPRIS D-Bus`；
    * **系统状态与输入法**：`PipeWire / PulseAudio`、`NetworkManager`、`BlueZ`、`UPower`、`Fcitx5 D-Bus`。
