# Island-proxy · v2rayN Island 方案设计

> **状态：方案设计阶段。** 当前仓库只保存交互/动效的 HTML 原型与设计说明，**不含任何可发布的实现代码**。计划 **2027 年** 开始正式落地。

## 项目定位

为 v2rayN 设计一套"灵动岛"风格的桌面悬浮交互：屏幕顶部居中的胶囊形组件，按需展开为信息卡片，用于展示代理状态、活跃度、辅助剪贴板等内容。

## 如何查看原型

直接用浏览器打开 `v2rayn_island.html` 即可。

- 原型通过 CDN 加载 Tailwind CSS（`cdn.tailwindcss.com/3.4.17`）和 Google Fonts（Inter、JetBrains Mono），**首次打开需要联网**。
- 页面中间有演示控制区，可切换各状态；还有若干可拖拽的测试项，用于演示"工作台/暂存架"。

## 原型涵盖的模块

以下依据原型源码中的分区注释整理：

**左侧岛（时间 + 多面板）**
- 折叠态胶囊（222×40）与展开内容
- 共享的"液态玻璃"滑动标签切换器，以及带方向性的模糊形变面板切换
- 面板 1：GitHub 风格活跃度热力图（含矩阵拖尾、列波动效果）
- 面板 2：辅助剪贴板（FLIP 位移 + 错峰入场 + 复制成功对勾反馈）
- 面板 3：工作台/暂存架（可接收文件、文件夹、快捷方式、txt 拖入）
- 音乐卡片展开态

**右侧岛（代理）**
- 安全导入确认卡片
- 瞬时 HUD / 嗅探 / 告警胶囊

**其他行为**
- 全屏时的"藏边"状态：组件上收，仅保留顶部 5px 发光边，鼠标移到顶部后下滑出现
- 剪贴板长文本悬停预览浮层

动效使用弹簧曲线（`--spring-ease`）与平滑曲线（`--smooth-ease`）两套缓动，由 `stepSpring` / `stepHeightSpring` 等函数驱动高度弹簧。

## 落地前的设计结论（性能与交互）

此前曾用 Rust + iced 0.14（wgpu / DX12 / `DxgiFromVisual` 透明窗口）做过一个简化的反馈弹窗原型，排查出"回缩卡顿"与"高压连续操作卡顿"的原因。该 Rust 代码已按要求移除，结论保留在此供正式实现时参考。**这些结论来自对依赖源码的阅读，尚未在真机上验证。**

1. **点击外部收起时不要同时触发窗口拖拽。** Windows 下 `drag_window` 会进入系统模态移动循环，导致渲染线程在回缩期间停摆。建议：展开态点击外部只做关闭；仅在闭合态按住并移动超过约 4px 才开始拖拽。
2. **动画帧不要依赖带容量上限的异步事件订阅。** 高频输入下事件通道可能溢出并丢掉重绘通知，动画会停在半途。建议在渲染阶段同步推进动画，并在动画未结束时主动请求下一帧。
3. **动画期间保持内部内容的布局尺寸不变，只改变外层裁剪尺寸。** 否则文本编辑器每帧都会重新排版。
4. **用连续进度驱动内容显隐（透明度渐变），避免状态切换的那一帧内容被瞬间卸载。** 同时避免回缩瞬间销毁输入法状态引起的停顿。
5. **不要在每帧渲染里做 O(N) 的整段文本拷贝来判断"是否可提交"。** 应缓存该状态，仅在编辑时更新。
6. **异步计时器（如提交中 → 成功 → 自动收起）必须可取消。** 否则快速连续开关会让旧计时器误关当前弹窗。
7. **如果落地后仍有卡顿，下一步排查渲染后端配置：** 透明窗口使用的 DX12 `DxgiFromVisual` 合成路径、呈现模式与帧延迟等待设置。
