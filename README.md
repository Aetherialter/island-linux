# island-demo — 双岛液态流体组件完整设计规范

> **项目定位**：面向 Linux Wayland 桌面环境（Niri / Hyprland / Sway）的双岛式常驻状态与效率中枢。  
> **当前阶段**：高定 Liquid Glass 视觉与物理交互原型定稿，计划于明年启动 Linux 原生工程开发。  
> **原型预览**：用浏览器直接打开 [v2rayn_island.html](./v2rayn_island.html)（首次加载 Tailwind CSS 与字体需联网）。

---

## 1. 整体空间架构与双岛对称布局

### 1.1 双岛功能分区（默认收起居中对称于桌面顶部）
* **左岛（个人效率与媒体中枢 · 默认收起 `222×40px`，展开 `416px` 宽）**
  * **时间与活力热力图（高度 `216px`）**：22 周活跃度网格（按列波浪入场）、底层 Matrix 字符雨与鼠标轨迹粒子光晕、悬停单格弹性日期统计提示。
  * **辅助粘贴板（高度 `250px`）**：支持高对比度深色搜索过滤、图片缩略图与 `0.34s` 悬停大图/全文浮层预览、FLIP 平滑置顶重排、删除/置顶操作事件隔离防误关、新条目呼吸光晕及 `vless://` / `vmess://` 节点链接一键嗅探导入。
  * **文件暂存工作栏（高度 `256px`）**：支持拖入唤醒（Drag-to-Wake），暂存本地文件、文件夹、`.desktop` 快捷方式与文本片段；卡片悬停 `0.5s` 弹出只读内容预览，向岛外拖拽释放可触发还原并移出暂存。
  * **媒体控制卡片（高度 `146px`）**：
    * **共享元素连续变形（Shared Element Morph）**：展开/回缩期间独立封面代理平滑插值位置、尺寸（`20px ↔ 96px`）、圆角（`6px ↔ 48px`）与内部图标尺寸（`12px ↔ 24px`），回缩时锁存等效最短角并沿最短路径回正至 `0°`。
    * **黑胶与流光动效**：黑胶封面惯性自转与平滑减速停驻、曲目主题双光源极光背景（Ambient Mesh Glow）、可点击/拖动的实时进度条，以及收起态胶囊溢出歌词自动平滑滚动。
* **右岛（极简状态小圆岛 · 默认收起 `40×40px`，展开 `456×466px`）**
  * **收起态纯状态图标**：平时仅呈 `40×40px` 居中纯状态圆点，严格区分三色语义——**绿色呼吸**（代理正常）、**灰色沉稳**（代理已关闭）、**红色告警**（节点超时/异常）；节点名称与延迟仅在点击展开后显露。
  * **场景一键切换**：开发分流 / 游戏 TUN / AI 全球，联动出口 IP 与流媒体/AI（Gemini / GPT）解锁状态徽章。
  * **核心开关与路由分段器**：系统代理（HTTP/SOCKS）与 TUN 虚拟网卡双开关、规则绕过 / 全局 / 直连三段式液态滑块。
  * **节点管理与吞吐监控**：真连接批量测速（附带完成声纳波纹扩散）与实时上下行双折线吞吐图。

### 1.2 镜像对称双向共存与隐藏机制
* **左岛展开时**：右岛不消失，平滑平移并保持 `40×40px` 纯状态圆岛贴靠在展开面板右侧。
* **右岛展开时**：左岛不消失，平滑收缩为 `78×40px` 的迷你时间/音乐胶囊停靠在展开面板左侧，点击可直接切换焦点面板。
* **全屏贴边隐藏（Peeking Bar）**：开启后无交互状态下自动上收隐藏至屏幕顶部边缘，仅留一条 `148×5px` 流光提示条，鼠标移至顶部 `20px` 热区即刻下拉唤出。
* **闲置变淡（Idle Dim）与壁纸压力测试**：桌面顶部 `3s` 无悬停且无展开交互时柔和淡化至 `0.72`（通过 `.is-shell-hidden` 严格隔离未激活壳层，杜绝幽灵重影）；内置深空暗夜、纯白高亮（自动切换烟熏液态玻璃保护对比度）与高饱和杂乱三套壁纸压力测试。

## 2. 液态玻璃质感、物理引擎与合岛体系

### 2.1 Liquid Glass（液态玻璃）光学材质
* **高透光学基底**：采用 `@supports` 检测下的 `in oklab` 无偏色渐变搭配 `backdrop-filter: blur(26px) saturate(210%) brightness(1.09)`，使桌面与壁纸色彩自然折射透出；动画期间全帧保持玻璃通透度，不再降级为不透明实色背景。
* **多层光学焦散与反射**：结合 `isolation: isolate`、`mix-blend-mode: screen` 斜向透镜反光、顶部强折光高光边与底部次级回光，配合随光标移动的 `210px` 径向追光折射描边。

### 2.2 弹簧物理与自适应高刷架构
* **物理积分模型**：所有形变（宽高、圆角、位移、融合度、合岛展开、碰撞冲量）均由二阶阻尼谐振子驱动，内置三套可调曲线（**Cult 柔弹** `k=215, c=21` / **液态丝滑** `k=150, c=18` / **极速干脆** `k=320, c=28`）。
* **原生高刷新率（Native VSync）**：基于 `requestAnimationFrame` 与 `dt` 归一化适配 60Hz–240Hz+ 显示器，静止时自动销毁循环实现 **0 帧空转**；展开内部采用定宽容器防止形变过程中的逐帧重排（Reflow）。

### 2.3 双岛物理拖拽、合岛融合与联合展开
* **物理拖拽弹簧（无彩色干扰带）**：拖拽双岛或撕裂合岛采用独立弹簧状态机与 `softRubber` 非线性橡胶阻力，搭配实时指针速度采样、体积守恒拉伸压扁与对面岛磁吸前倾；不显示两岛间隙的彩色光斑条，未过阈值松手带惯性过冲平滑回弹。
* **丝滑合岛 / 分裂（`#fusedIsland`）**：
  * **合岛过渡**：双岛向心加速靠拢碰撞、挤压收束后再弹性舒展过冲定型为居中 `372×42px` 超级控制条；音乐关闭时左侧显示时钟与日期，开启音乐时切换为曲名与与左岛统一风格的琉璃圆角播放 3 键（固定靠右紧贴中线分隔线）。
  * **稳态右区与过渡动效**：右侧代理快捷开关胶囊锁定 `102px` 固定宽度，切换开启/关闭/超时带平滑色彩渐变、圆点缩放、胶囊轻弹与文字上浮动画，且分隔线 `|` 绝对静止。
  * **拆岛过渡**：分裂瞬间底层左右双岛预先在合体胶囊左右半区就位，随手势撕裂动量直接向两侧弹射拉开。
* **超级岛原地展开（`468×266px` 双栏联合中控）**：
  * 点击超级岛左区/空白或按 `Alt + Space` 可原地平滑展开；左卡随模式动态联动大时钟、音乐动效（黑胶旋转、EQ 音柱、主题流光、切歌与歌词动画同步）、剪贴板与工作栏速览，右卡提供系统代理/TUN 开关与路由模式快捷切换。

## 3. 微交互与触觉反馈清单

1. **方向性形变生长原点**：左岛形变锚点偏左（`22% 14%`），右岛偏右（`78% 14%`），确保扩张与回缩顺应顶栏物理站位自然生长。
2. **双域滚轮切换与防抖稳态**：
   * 独立左岛收起态、合岛收起态左半区、以及合岛展开态左卡均支持鼠标滚轮循环切换 `时间活力图 ↔ 辅助粘贴板 ↔ 工作栏 ↔ 音乐播放器`；
   * 收起胶囊切换带轻柔竖向果冻回弹（经 `240ms` 节流与限速防抽搐），合岛展开态锁定外框绝对静止，仅内部面板上下滑入切换。
3. **局部微动效（Micro-Interactions）**：
   * **果冻开关（Squash & Stretch）**：切换系统代理或 TUN 开关时，滑块触发横向拉伸与纵向回弹形变；
   * **声纳脉冲波纹（Sonar Ripple）**：测速完成瞬间，延迟胶囊外圈扩散翠绿声纳波纹；
   * **黑洞漩涡吸入与弹跳落位**：拖入文件至工作栏松手瞬间，光标处旋起冷蓝引力漩涡，新卡片以弹性缩放落入网格。

## 4. 快捷操作与键盘流规范

### 4.1 鼠标快捷操作
* **左岛 / 合岛左侧（含合岛展开左卡）滚轮**：循环切换 `时间活力图 ↔ 辅助粘贴板 ↔ 工作栏 ↔ 音乐播放器`。
* **右岛收起态右键 / 合岛右侧状态胶囊左键**：快捷开/关总代理（记忆上次系统代理 / TUN 状态组合，一键关闭呈灰色状态，再次操作恢复开启）。

### 4.2 全局快捷键（支持重复按键「开启 ↔ 关闭」循环切换）
> 注：Web 原型中暂用 `Alt` 映射未来 Linux 桌面的 `Super` 键；即使搜索框处于输入聚焦状态，再次按下同一快捷键仍可直接收起面板。

| 快捷键（Linux / Web） | 功能行为 | 重复按下行为 |
| :--- | :--- | :--- |
| `Super / Alt + Space` | 分离态唤起左岛默认面板 / 合岛态展开联合中控 | 平滑收起至胶囊态 |
| `Super / Alt + V` | 直达左岛「辅助粘贴板」并自动聚焦搜索框 | 收起左岛面板 |
| `Super / Alt + W` | 直达左岛「文件暂存工作栏」 | 收起左岛面板 |
| `Super / Alt + P` | 展开右岛「代理控制中心」并立即触发批量测速 | 收起右岛面板 |
| `Esc` | 失焦并收起当前任意展开的单岛或超级岛面板 | — |

## 5. 明年 Linux 正式落地技术路线参考

* **路线 A：Wayland 原生轻量组件（首选推荐）**
  * **技术栈**：`GTK4` + `gtk4-layer-shell`（Rust 或 Python） / `Quickshell` / `AGS`。
  * **优势**：无浏览器内核，常驻内存约 `30~50 MB`，直接挂载 Wayland Top Layer 并走合成器硬件加速，续航与响应最佳。
* **路线 B：复用现有前端动效架构**
  * **技术栈**：`Tauri v2`（WebKitGTK） + Rust 后端守护进程。
  * **系统接口对接**：
    * 代理控制：对接 `v2rayN` / `sing-box` Clash RESTful API（节点切换、真连接测速、实时流量 WebSocket）；
    * 剪贴板与拖放：对接 `wl-clipboard` 监听文本/图片历史，及 Wayland `wl_data_device` 原生文件拖拽协议；
    * 媒体控制：对接 Linux 标准 `MPRIS D-Bus` 接口获取播放进度、封面与歌词。
