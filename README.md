# island-demo — 双岛液态流体组件完整设计规范

> **项目定位**：面向 Linux Wayland 桌面环境（Niri / Hyprland / Sway）的双岛式常驻状态与效率中枢。  
> **当前阶段**：高定动效与交互原型验证完成，计划于明年启动 Linux 原生工程开发。  
> **原型预览**：用浏览器直接打开 [v2rayn_island.html](./v2rayn_island.html)（首次加载 Tailwind CSS 与字体需联网）。

---

## 1. 整体空间架构与双岛对称布局

### 1.1 双岛功能分区
* **左岛（个人效率与媒体中枢 · 默认收起 `222×40px`，展开 `416px` 宽）**
  * **时间与活力热力图（高度 `216px`）**：22 周活跃度网格（按列波浪入场）、底层 Matrix 字符雨与鼠标轨迹粒子光晕、悬停单格弹性日期统计提示。
  * **辅助粘贴板（高度 `250px`）**：支持高对比度深色搜索过滤、图片缩略图与 `0.34s` 悬停大图/全文浮层预览、FLIP 平滑置顶重排、新条目呼吸光晕及 `vless://` / `vmess://` 节点链接一键嗅探导入。
  * **文件暂存工作栏（高度 `256px`）**：支持拖入唤醒（Drag-to-Wake），暂存本地文件、文件夹、`.desktop` 快捷方式与文本片段；卡片悬停 `0.5s` 弹出只读内容预览，向岛外拖拽释放可触发还原并移出暂存。
  * **媒体控制卡片（高度 `146px`）**：支持黑胶唱片封面惯性自转（暂停时角速度平滑减速停住而非生硬定格）、根据封面主色调呼吸的动态双光源极光背景（Ambient Mesh Glow）、可点击/拖动的实时进度条，以及收起态胶囊内溢出歌词自动平滑滚动。
* **右岛（v2rayN 网络代理控制中心 · 默认收起 `118×40px`，展开 `456×522px`）**
  * **场景一键切换**：开发分流 / 游戏 TUN / AI 全球，联动出口 IP 与流媒体/AI（Gemini / GPT）解锁状态徽章。
  * **核心开关与路由分段器**：系统代理（HTTP/SOCKS）与 TUN 虚拟网卡双开关、规则绕过 / 全局 / 直连三段式液态滑块。
  * **节点管理与吞吐监控**：真连接批量测速（附带完成声纳波纹扩散）、实时上下行双折线吞吐图、以及一键复制 PowerShell / Bash 代理环境变量与唤起主窗口。

### 1.2 镜像对称双向共存机制（Symmetric Co-Existence）
* **左岛展开时**：右岛不消失，平滑收缩为 `78×40px` 的紧凑状态胶囊（仅保留状态呼吸灯与延迟徽章）停靠在展开面板右侧。
* **右岛展开时**：左岛同样不消失，平滑收缩为 `78×40px` 的迷你时间/音乐胶囊停靠在展开面板左侧，点击可直接切换焦点面板。
* **全屏贴边隐藏（Peeking Bar）**：开启后无交互状态下自动上收隐藏至屏幕顶部边缘，仅留一条 `148×5px` 流光提示条，鼠标移至顶部 `20px` 热区即刻下拉唤出。

## 2. 流体物理引擎与动效规范

### 2.1 弹簧物理与自适应高刷架构
* **物理积分模型**：所有形变（宽高、圆角、位移、融合度、碰撞冲量）均由二阶阻尼谐振子（Hooke's Law + Damping）驱动，内置三套可调曲线（**Cult 柔弹** `k=215, c=21` / **液态丝滑** `k=150, c=18` / **极速干脆** `k=320, c=28`）。
* **原生高刷新率（Native VSync）**：基于 `requestAnimationFrame` 与帧间 `dt` 归一化，直接跑满显示器原生刷新率（60Hz / 120Hz / 144Hz / 240Hz+），静止时循环自动销毁实现 **0 帧空转**。
* **渲染性能隔离通道**：
  * 弹簧运动期间（`.is-animating`）临时关闭大面积实时高斯模糊重采样，落定瞬间立即恢复完整磨砂液态玻璃质感；
  * 展开内容区锁定固定排版宽度，形变过程仅做外框裁剪，消除逐帧重排（Reflow）。

### 2.2 双岛磁吸碰撞与液态融合（Metaball Fusion）
* **黏性液桥（Viscous Metaball Bridge）**：当两岛靠近、推挤或处于共存状态且间距小于 `36px` 时，间隙自动拉出一道带高斯模糊高光的液态桥梁，随距离动态拉伸与淡入淡出。
* **弹性碰撞反馈**：展开一侧岛屿时向另一侧传递弹性碰撞冲量，产生真实的微幅弹开与阻尼回位。
* **超级宽岛融合 / 分裂**：触发融合时两岛向心磁吸吞并为居中 `372×42px` 超级胶囊（同屏聚合显示时间、当前节点与延迟），点击分裂则如水滴般弹射分离回双岛形态。

## 3. 极致微交互与触觉反馈清单

1. **方向性形变生长原点**：左岛形变锚点偏左（`22% 14%`），右岛偏右（`78% 14%`），确保扩张与回缩顺应顶栏物理站位自然生长。
2. **边界橡皮筋阻尼（Rubber-band Overscroll）**：收起态左岛滚轮快切模式，以及节点列表、粘贴板、工作栏滚动触顶/触底继续滑动时，触发弹性拉伸位移与弹簧回弹（同时刻意移除鼠标靠近外围热区的磁吸漂移，保持静止稳重）。
3. **局部微动效（Micro-Interactions）**：
   * **果冻开关（Squash & Stretch）**：切换系统代理或 TUN 开关时，白色滑块触发横向拉伸与纵向回弹形变；
   * **声纳脉冲波纹（Sonar Ripple）**：单节点或批量测速完成瞬间，延迟胶囊外圈扩散翠绿声纳波纹；
   * **黑洞漩涡吸入与弹跳落位**：拖入文件至工作栏松手瞬间，光标处旋起冷蓝引力漩涡，新卡片以弹性缩放落入网格；
   * **光标边缘折射高光（Halo Specular Border）**：鼠标悬停在胶囊表面时，边框出现随光标移动的冷白径向折射高光。

## 4. 快捷操作与键盘流规范

### 4.1 鼠标零展开盲操
* **左岛收起态滚轮**：直接循环切换 `时间活力图 ↔ 辅助粘贴板 ↔ 工作栏 ↔ 音乐播放器`（附带上下方向性模糊滑入动画）。
* **右岛收起态右键**：直接盲操切换「系统代理」开关，无需展开面板（刻意禁用右岛滚轮切节点，避免信息量少时盲切无法感知结果）。

### 4.2 全局快捷键（支持重复按键「开启 ↔ 关闭」循环切换）
> 注：Web 原型中暂用 `Alt` 映射未来 Linux 桌面的 `Super` 键；即使搜索框处于输入聚焦状态，再次按下同一快捷键仍可直接收起面板。

| 快捷键（Linux / Web） | 功能行为 | 重复按下行为 |
| :--- | :--- | :--- |
| `Super / Alt + Space` | 唤起双岛默认面板 | 平滑收起至双胶囊态 |
| `Super / Alt + V` | 直达左岛「辅助粘贴板」并自动聚焦搜索框 | 收起左岛面板 |
| `Super / Alt + W` | 直达左岛「文件暂存工作栏」 | 收起左岛面板 |
| `Super / Alt + P` | 展开右岛「代理控制中心」并立即触发批量测速 | 收起右岛面板 |
| `Esc` | 失焦并收起当前任意展开的面板 | — |

## 5. 明年 Linux 正式落地技术路线参考

* **路线 A：Wayland 原生轻量组件（首选推荐）**
  * **技术栈**：`GTK4` + `gtk4-layer-shell`（Rust 或 Python） / `Quickshell` / `AGS`。
  * **优势**：无浏览器内核，常驻内存约 `30~50 MB`，直接挂载 Wayland Top Layer 并走合成器硬件加速，续航与响应最佳。
* **路线 B：复用现有前端动效架构**
  * **技术栈**：`Tauri v2`（WebKitGTK） + Rust 后端守护进程。
  * **系统接口对接**：
    * 代理控制：对接 `v2rayN` / `sing-box` Clash RESTful API（节点切换、真连接测速、实时流量 WebSocket）；
    * 剪贴板与拖放：对接 `wl-clipboard` 监听文本/图片历史，及 Wayland `wl_data_device` 原生文件拖拽协议；
    * 媒体控制：对接 Linux 标准 `MPRIS D-Bus` 接口获取播放进度、封面与歌词。
